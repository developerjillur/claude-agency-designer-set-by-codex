# Sample photos

Photos for the pattern library's fictional sample brand (Tidewater Coffee Roasters). They were generated with the
`codex-imagegen` skill (GPT Image through the Codex CLI), judged by its image judge, and exported as WebP. Each file
declares in its metadata that it is AI-generated (IPTC DigitalSourceType trainedAlgorithmicMedia). Replace them with
the client's own photos or plates in real work.

| File | Used by |
|---|---|
| `roastery-4x5.webp` | post-photo (feed presets) |
| `roastery-9x16.webp` | post-photo on stories, story |
| `cup-2x3.webp` | pin |
| `counter-16x9.webp` | blog-featured |
| `grinder-hands.webp` (transparent) | thumbnail |
| `bag-cutout.webp` (transparent) | post-product, product-infographic, sign |
